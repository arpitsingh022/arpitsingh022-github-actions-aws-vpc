
# GitHub Actions AWS VPC

Automate AWS VPC infrastructure provisioning using Terraform and GitHub Actions.

## AWS Resources

- VPC
- Public Subnet
- Private Subnet
- Internet Gateway
- Public Route Table
- Private Route Table
- Route Table Associations
- Security Group

## Technologies

- AWS
- Terraform
- Git
- GitHub
- GitHub Actions

## AWS Region

ap-south-1 (Mumbai)

## Deployment

GitHub Actions runs Terraform initialization, formatting,
validation and planning. Infrastructure deployment is
triggered manually using workflow_dispatch.
